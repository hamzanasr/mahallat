# منصة محلات · Mahallat Platform

منصة توصيل طلبات سريعة ومرنة، مبنية بنظام **Monorepo** يجمع بين تطبيقات الجوال ولوحات التحكم في مكان واحد.

---

## 🛠 المتطلبات الأساسية

قبل البدء، تأكد من تثبيت البرامج التالية على جهازك (Windows):
1. **Node.js**: الإصدار المستقر الحديث (v20+ أو v26).
2. **Git**: مثبت ومُعرّف باسمك وبريدك.
3. **تطبيق Expo Go**: مثبت على جوالك من متجر App Store أو Google Play لتجربة تطبيق الجوال.

---

## 🚀 خطوات التشغيل خطوة بخطوة على Windows

افتح سطر الأوامر (PowerShell) في مجلد المشروع، ونفّذ الأوامر التالية:

### 1. تثبيت جميع الحزم والتبعيات
```powershell
npm install
```

### 2. تشغيل لوحة الويب (Next.js)
```powershell
npm run dev:web
```
- افتح المتصفح على: [http://localhost:3000](http://localhost:3000)
- سترى واجهة المنصة باللغة العربية مع إمكانية التبديل إلى الإنجليزية مع تغيير اتجاه الصفحة تلقائياً.

### 3. تشغيل تطبيق العميل للجوال (Expo)
```powershell
npm run dev:customer
```
- سيظهر لك رمز استجابة سريعة (QR Code) في شاشة الأوامر.
- افتح تطبيق **Expo Go** على جوالك وامسح الرمز لتشغيل التطبيق.
- **ملاحظة:** يجب أن يكون جوالك والكمبيوتر متصلين على نفس شبكة الواي فاي (Wi-Fi). وإذا لم يفتح، يمكنك تشغيله عبر خيار النفق:
  ```powershell
  npx --workspace=apps/customer expo start --tunnel
  ```

### 4. فحص صحة الكود وجودته
```powershell
npm run typecheck    # فحص توافق الأنواع في TypeScript
npm run lint         # فحص أسلوب الكود وجودته
```

### 5. تشغيل الاختبارات الآلية (Vitest)
```powershell
npm test
```

## 📁 هيكل المشروع (Monorepo)

- **`apps/web`**: تطبيق الويب ولوحات التحكم (مبني بـ Next.js و Tailwind CSS).
- **`apps/customer`**: تطبيق العميل للهواتف الذكية (مبني بـ Expo و React Native و expo-router).
- **`packages/shared`**: الحزمة المشتركة التي تضم:
  - ملفات النصوص والترجمة (`i18n/ar.json`, `i18n/en.json`).
  - دوال تحديد اتجاه الصفحة واللغات (`getDirection`, `isRTL`).
  - مجلد مخصص للأنواع المولّدة من قاعدة البيانات Supabase.
- **`docs/`**: جميع المواصفات الفنية وخارطة الطريق وسجلات التقدم.

---

## 🌐 قواعد اللغات (i18n)
- المنصة تعتمد **العربية أولاً** باتجاه من اليمين لليسار (`rtl`).
- لا يتم كتابة أي نص ظاهر داخل كود الشاشات مباشرة؛ كل النصوص تُستورد حصراً من `packages/shared/src/i18n`.
