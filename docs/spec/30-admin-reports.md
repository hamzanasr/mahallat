# تقارير الإدارة

61 تقريراً في صفحة «التقارير» بلوحة الإدارة، لتكون عندك نظرة متكاملة لكل شيء. الصورة في «لوحة الإدارة ← التقارير».

- كل تقرير: فلتر الفترة والمدينة والقسم، والمقارنة بالفترة السابقة، والضغط على أي رقم يفتح تفاصيله.
- تصدير Excel وPDF، وإرسال مجدول بالبريد يومياً أو أسبوعياً أو شهرياً.
- حفظ فلاتر التقرير كعرض خاص، ومشاركته مع دور معين.
- ملخص صباحي يصلك كل يوم: طلبات أمس، والإلغاء، والتأخير، والإيراد، وأكبر 3 مشاكل.
- كل التقارير متاحة أيضاً عبر المساعد الذكي (MCP) بلغة عادية.
