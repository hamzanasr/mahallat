# التسليم والقبول

- تسليم المصدر وحسابات الخدمات باسم المالك، لا تحت حساب شخصي للمبرمج
- دليل تشغيل ونشر يمكّن فريقاً آخر من تشغيل بيئة التجربة
- اختبار قبول لكل معرّف متطلب في هذه الصفحة مع نتيجته
- حماية بيانات العملاء والمدفوعات: البطاقات تُحفظ عبر ميسر لا في خوادم المنصة، وكل طرف يرى بياناته فقط
