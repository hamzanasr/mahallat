# الصيدليات

قسم مستقل بطلبات الكتابة، مع مراجعة صيدلي. يحتاج تأكيداً نظامياً قبل التفعيل.

1.  **من ينضم**صيدلية مجتمعية مرخصة ولها موقع فعلي فقط. تُسجَّل أرقام ترخيص وزارة الصحة والهيئة العامة للغذاء والدواء والسجل التجاري وتواريخ انتهائها. انتهاء أي ترخيص يوقف الصيدلية تلقائياً.

2.  **الطلب كتابة**لا يوجد منيو. العميل يكتب طلبه نصاً، ويرفق الوصفة الطبية إن وُجدت، ويدفع التوصيل أولاً.

3.  **تنبيه الوصفة**قبل الإرسال يظهر للعميل بوضوح: إذا كان الدواء يحتاج وصفة ولم ترفقها، سيُلغى الطلب.

4.  **مراجعة الصيدلي**يصل الطلب للصيدلي فيتأكد منه ومن الوصفة، ويتواصل مع العميل بالشات إذا احتاج. الطلب الوصفي بلا وصفة يُلغى.

5.  **الفاتورة والسداد**الصيدلي يجهز الطلب ويرفع الفاتورة بمبلغها حتى قبل وصول المندوب. تُضاف 5% ورسوم الخدمة، ويصل للعميل طلب السداد. المندوب لا يستلم قبل السداد.

6.  **التغليف والتوصيل**كيس مغلق، والمندوب لا يرى الوصفة. المنتجات التي تحتاج تبريداً تُسند لمندوب لديه حقيبة تبريد.

7.  **الخصوصية**الوصفة يراها صيدلي الصيدلية والإدارة المخولة فقط، والإشعارات لا تذكر اسم الدواء.

8.  **الاسترجاع**لا تُسترجع الأدوية بعد التسليم إلا في حال التلف أو الخطأ.

(رسم توضيحي) مسار طلب الصيدلية: مكتوب ودفع التوصيل، ثم مراجعة، ثم فاتورة وسداد، ثم التوصيل.

- الوصفة صالحة للصرف حتى 3 أشهر.
- لا إعلان للأدوية الوصفية. إعلان الأدوية بدون وصفة يحتاج موافقة الهيئة العامة للغذاء والدواء.
- إذا لم يتجاوب العميل تصبح حالة الطلب «يعود للصيدلية»، ولا يُغلق قبل أن تؤكد الصيدلية استلامه. رسوم التوصيل لا تُسترد، وثمن الدواء يُسترد إذا أكدت الصيدلية سلامة إعادته.

**قبل التفعيل:** البيع الإلكتروني للأدوية في السعودية خدمة إضافية لصيدلية مجتمعية مرخصة ولها موقع فعلي، والأدوية الخاضعة للرقابة ممنوعة إلكترونياً. يُراجع مستشار نظامي أو وزارة الصحة والهيئة العامة للغذاء والدواء قبل الإطلاق.
