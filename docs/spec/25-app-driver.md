# تطبيق المندوب

كل الطلبات في صفحة واحدة، ثم المهمة من الاستلام حتى التسليم، والخدمات والمستندات والأرباح والأداء.

#### شاشة: الطلبات

كل الأنواع في صفحة واحدة، وكل نوع بوسم لون. حتى 3 طلبات معه، ولا تُجمع إلا إذا كان العملاء داخل كيلو متر واحد.
