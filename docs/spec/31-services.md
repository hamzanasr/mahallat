# الربط مع الخدمات الأخرى

طريقة الربط يقررها المبرمج.

| الخدمة                                                          | الغرض                                                                                                                                                           | هل يتوقف الطلب إن تعطلت؟             |
|-----------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------|
| **ميسر**                                                        | الدفع والحجز والتحصيل والاسترداد، وتحويل مستحقات التجار والمناديب والشركات من حساب ميسر                                                                         | نعم                                  |
| **أنظمة الكاشير**                                               | فودكس، مرن، Sapaad، Touché، NCR Aloha، Oracle Simphony، iiko، berryPOS، Odoo، رواء، قيود، سند، Loyverse، جيديا، EZPOS: إرسال الطلب لنظام التاجر وإصدار الفاتورة | لا · يرفع التاجر الفاتورة يدوياً      |
| **الفوترة الإلكترونية (هيئة الزكاة)**                           | فواتير المنصة الضريبية                                                                                                                                          | لا · تُرسل لاحقاً خلال المهلة النظامية |
| **Odoo**                                                        | المحاسبة والتسويات وفواتير المنصة                                                                                                                               | لا                                   |
| **OneSignal**                                                   | إشعارات الطلب، والتسويقية لفئات (عملاء محددون، مدن، طلبات أكبر من مبلغ)، والذكاء الاصطناعي يقترح النص والفئة                                                    | لا · يبقى سجل داخل التطبيق           |
| **مزود الرسائل والاتصال المقنع**                                | رموز الدخول، والمكالمات بين العميل والمندوب، ورسالة نصية احتياطية للإشعارات المهمة                                                                              | الدخول فقط                           |
| **قراءة الفواتير آلياً**                                         | قراءة مبلغ الفاتورة من صورة المندوب في طلبات غير المتعاقد                                                                                                       | لا · المندوب يُدخل المبلغ             |
| **التحقق من الوجه**                                             | وجه سائق Taxi قبل المناوبة                                                                                                                                      | لا · مراجعة يدوية                    |
| **الخرائط**                                                     | المدن والمسافات والتتبع ونطاق 100 متر، وكشف تزوير الموقع                                                                                                        | نعم للتتبع                           |
| **Adjust**                                                      | روابط المتاجر ودعوة صديق وقياس مصدر الزيارة                                                                                                                     | لا                                   |
| **Mixpanel**                                                    | تحليل رحلة العميل                                                                                                                                               | لا                                   |
| **المساعدات الذكية عبر خادم MCP (مثل Claude وChatGPT وGemini)** | المدير يسأل عن الطلبات والمبيعات والمناديب والمالية والتقارير بلغة عادية، بصلاحياته، والقراءة افتراضياً                                                          | لا                                   |
