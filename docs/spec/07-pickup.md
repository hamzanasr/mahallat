# الاستلام الذاتي

- المدير يفعّل الاستلام الذاتي لكل متجر يريده، **ومنها متاجر المارت**.
- **رسوم التاجر نفسها** حسب عقده: رسوم لكل عميل أو نسبة.
- المدير يحدد **نسبة خصم الاستلام**، و**من يتحمله**: المنصة أو التاجر أو الاثنان بنسب يحددها.
- رسوم الخدمة على العميل حسب الإعدادات، ورسم الدفع على التاجر. لا توصيل ولا مندوب.
- التاجر يسلّم العميل الطلب **بكود العميل**.

### إذا تأخر العميل

1.  **تذكير عند الجاهزية**لحظة ضغط التاجر «جاهز»: الطلب جاهز، وإذا لم يُستلم قبل نهاية الدوام يُنهى الطلب ويُسحب المبلغ.

2.  **بعد 60 دقيقة**تنبيه: التطبيق غير مسؤول عن تأخر الاستلام، ولا عن تلف الطلب أو ما يحصل له.

3.  **نهاية دوام المتجر**يُغلق الطلب «لم يُستلم»، ويُحصَّل المبلغ للتاجر.
