# السلة وإتمام الطلب CRT

## CRT-001 · السلة والملاحظات

- **الأولوية:** مهم

**القواعد**

- سلة لمتجر واحد
- الأحجام والإضافات وملاحظات العميل تظهر للتاجر
- تنبيه صغير للعميل: الملاحظات غير ملزمة للتاجر
- النظام يعيد حساب السعر والتوفر قبل الدفع

**معيار القبول**

- [ ] التنبيه يظهر بجانب خانة الملاحظات

## CRT-002 · شريط التوصيل المجاني

- **الأولوية:** أساسي للإطلاق

**القواعد**

- يظهر المتبقي لتحقيق عرض توصيل مجاني ساري في مدينة المتجر

**معيار القبول**

- [ ] حذف صنف يُنقص التأهل فوراً
- [ ] لا يُعلن مجاناً لمتجر غير مشترك في العرض

## CRT-003 · الإضافات المقترحة

- **الأولوية:** أساسي للإطلاق

**القواعد**

- مقترحات من المتجر نفسه دون إضافة تلقائية

**معيار القبول**

- [ ] ضغطة الإضافة تعدّل السلة مرة واحدة

## CRT-004 · انتهاء السلة

- **الأولوية:** أساسي للإطلاق

**القواعد**

- تنتهي بنهاية دوام المتجر، و24 ساعة للمتاجر العاملة طوال اليوم
- السلة لا تحجز مخزوناً ولا سعراً

**معيار القبول**

- [ ] العودة بعد الانتهاء تبدأ سلة جديدة أو تعيد التحقق من الأصناف

## CRT-005 · تفصيل الرسوم قبل الدفع

- **الأولوية:** أساسي للإطلاق

**القواعد**

- ملخص الدفع يعرض كل بند وحده: المنتجات، والتوصيل، ورسوم الخدمة 2.5%، والخصم، والإكرامية، والمبلغ المستخدم من المحفظة
- زيادة السعر المضمّنة في المنتج لا تظهر بنداً منفصلاً ( PAY-009 )

**معيار القبول**

- [ ] مجموع البنود يساوي المبلغ المحجوز
