# Taxi TAX

## TAX-001 · قسم Taxi

- **الأولوية:** أساسي للإطلاق

**القواعد**

- قسم Taxi مطلوب ضمن المنصة، وتفاصيله في ملف مستقل لاحقاً
- المندوب لا يرى Taxi إلا بموافقة الإدارة
- التحقق من وجه السائق قبل كل مناوبة Taxi
- السائق الذي يلغي 3 مشاوير بعد قبولها يُحظر مباشرة

**معيار القبول**

- [ ] لا يبدأ السائق مناوبة Taxi بلا تحقق الوجه
- [ ] الإلغاء الثالث بعد القبول يحظر السائق تلقائياً
