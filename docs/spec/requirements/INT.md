# الخدمات المرتبطة INT

## INT-001 · ميسر

- **الأولوية:** أساسي للإطلاق

**القواعد**

- بيئة تجربة ثم تشغيل
- مطابقة يومية مع تقرير ميسر

**معيار القبول**

- [ ] دفع ناجح وفاشل ومسترد يظهر بشكل صحيح

## INT-004 · الإشعارات والرسائل

- **الأولوية:** أساسي للإطلاق

**القواعد**

- الإشعارات عبر OneSignal
- إشعارات الطلب منفصلة عن التسويقية
- المدير يرسل إشعاراً لفئة: عملاء محددون، أو مدن معينة، أو من طلباتهم أكبر من مبلغ، أو من لم يطلب منذ مدة
- الذكاء الاصطناعي مدمج: يقترح نص الإشعار والفئة المناسبة، والمدير يعتمد
- رموز الدخول برسائل نصية
- خريطة الإشعارات الكاملة في قسم «الإشعارات»

**معيار القبول**

- [ ] إشعار الطلب يفتح الطلب الصحيح لصاحبه فقط
- [ ] الإشعار التسويقي لا يصل لمن ألغى موافقة التسويق

## INT-006 · الفوترة الإلكترونية

- **الأولوية:** أساسي للإطلاق · **نظامي**

**القواعد**

- فواتير المنصة تُرسل لهيئة الزكاة ضمن المهلة النظامية
- فواتير عمولة التاجر ورسومه (بين منشأتين) تُعتمد من الهيئة قبل إصدارها
- فواتير العميل المبسطة تُبلَّغ خلال 24 ساعة
- يُراجَع البند المفتوح عن التجار بلا كاشير في ضوء الموجة 25

**معيار القبول**

- [ ] فشل الإرسال يُعاد ويُصعَّد قبل انتهاء المهلة
- [ ] لا تصدر فاتورة عمولة للتاجر قبل اعتمادها من الهيئة
- [ ] فاتورة مبسطة لم تُبلَّغ خلال 24 ساعة تُصعَّد

## INT-008 · تحليل رحلة العميل

- **الأولوية:** أساسي للإطلاق

**القواعد**

- قياس المسار من زيارة المتجر حتى إكمال الطلب دون بيانات شخصية حساسة

**معيار القبول**

- [ ] فشل التحليلات لا يوقف الشراء

## INT-009 · روابط المتاجر

- **الأولوية:** أساسي للإطلاق

**القواعد**

- رابط يفتح المتجر داخل التطبيق على iOS وAndroid، أو المتجر لتنزيله

**معيار القبول**

- [ ] رابط فرع محذوف يعرض بديلاً مفهوماً

## INT-010 · Odoo

- **الأولوية:** أساسي للإطلاق

**القواعد**

- المحاسبة والتسويات وفواتير المنصة

**معيار القبول**

- [ ] توقف Odoo لا يوقف الطلبات

## INT-011 · المساعدات الذكية عبر MCP

- **الأولوية:** أساسي للإطلاق

**القواعد**

- خادم MCP للمنصة يربطها بالمساعدات الذكية مثل Claude وChatGPT وGemini
- استعلامات تشغيلية ومحاسبية بصلاحيات المستخدم، والقراءة افتراضياً
- أي إجراء مالي يحتاج موافقة من داخل لوحة الإدارة
- كل استعلام مسجل بالمستخدم والوقت

**معيار القبول**

- [ ] طلب بيانات فرع غير مخول يُرفض
- [ ] إيقاف الربط من لوحة الإدارة يوقفه فوراً

## INT-012 · واجهة الشركاء

- **الأولوية:** مهم

**القواعد**

- واجهة موثقة للشركاء وأنظمة الكاشير والمنصات الوسيطة
- تغطي الطلبات والمنيو والمخزون وحالة المتجر
- لها بيئة تجربة
- تُضاف إدارة الطلبات داخل نظام الكاشير عند طلب مزوديه

**معيار القبول**

- [ ] الشريك يصل إلى بيانات متاجره المرتبطة فقط
