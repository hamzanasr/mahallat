# الامتثال النظامي REG

## REG-001 · ترخيص تطبيق التوصيل

- **الأولوية:** أساسي للإطلاق · **نظامي**

**القواعد**

- لا يُطلق التطبيق تجارياً قبل ترخيص نشاط تطبيقات التوصيل من الهيئة
- يُعرض رقم الترخيص في التطبيق

**معيار القبول**

- [ ] رقم الترخيص ظاهر في التطبيق عند الإطلاق التجاري

## REG-002 · البيانات الغذائية في المنيو

- **الأولوية:** أساسي للإطلاق · **نظامي**

**القواعد**

- تُطبَّق متطلبات SFDA عبر CUS-019 وMER-025
- يُراجَع النص الأصلي للائحة SFDA للتأكد من نطاق المرحلة الثانية

**معيار القبول**

- [ ] نتيجة المراجعة موثقة قبل الإطلاق

## REG-003 · المنافسة والشفافية

- **الأولوية:** مهم · **نظامي**

**القواعد**

- سياسة ترتيب وظهور مكتوبة ومحفوظة، مع تمييز الإعلانات كما في CUS-003
- شروط تاجر موحدة منشورة لكل نوع تشغيل
- تخلو العقود من شرط الحصرية

**معيار القبول**

- [ ] تاجران من نوع التشغيل نفسه يخضعان للشروط المنشورة نفسها

## REG-004 · حماية البيانات الشخصية

- **الأولوية:** أساسي للإطلاق · **نظامي**

**القواعد**

- سجل موافقات، وطلبات أصحاب البيانات: اطلاع وتصحيح وحذف
- خطة تسرب تُخطر الجهة خلال 72 ساعة
- مدد حفظ لكل نوع بيانات، منها الوصفات
- ربط المساعدات الذكية بالمنصة يتم عبر خادم MCP بصلاحيات المستخدم ( INT-011 )

**معيار القبول**

- [ ] طلب صاحب البيانات يُسجَّل ويُتابع حتى إغلاقه
- [ ] كل استعلام من المساعد الذكي مسجل باسم المستخدم ووقته

## REG-006 · اعتماد برنامج «هدف»

- **الأولوية:** مهم

**القواعد**

- تقديم طلب اعتماد التطبيق لدى برنامج دعم مناديب التوصيل
- توفير تقارير عدد التوصيلات المطلوبة ( DRV-022 )

**معيار القبول**

- [ ] تقرير عدد التوصيلات متاح لكل مندوب سعودي

## REG-007 · الاشتراطات البلدية

- **الأولوية:** مهم · **نظامي**

**القواعد**

- مراجعة قانونية للاشتراطات البلدية لخدمات التوصيل المنزلي
- تحويل ما يخص التطبيق إلى متطلبات

**معيار القبول**

- [ ] نتيجة المراجعة موثقة ومربوطة بمعرّفات المتطلبات

## REG-008 · التجارة الإلكترونية والتخفيضات

- **الأولوية:** مهم · **نظامي**

**القواعد**

- مراجعة قانونية لمتطلبات إفصاح الرسوم والأسعار والاسترداد وترخيص العروض

**معيار القبول**

- [ ] نتيجة المراجعة موثقة ومربوطة بمعرّفات المتطلبات
