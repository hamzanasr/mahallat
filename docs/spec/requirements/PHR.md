# الصيدليات PHR

## PHR-001 · حد الأشهر الثلاثة

- **الأولوية:** أساسي للإطلاق · **نظامي**

**القواعد**

- لا يعتمد الصيدلي كمية دواء وصفي تتجاوز احتياج 3 أشهر حسب الوصفة
- يسجّل الصيدلي الكمية المعتمدة

**معيار القبول**

- [ ] كمية تتجاوز احتياج 3 أشهر لا تُعتمد
- [ ] الكمية المعتمدة محفوظة مع الطلب

## PHR-002 · عناصر الوصفة الإلزامية

- **الأولوية:** أساسي للإطلاق · **نظامي**

**القواعد**

- شاشة مراجعة الصيدلي تعرض قائمة تحقق بعناصر الوصفة: اسم المريض، والطبيب، والدواء، والجرعة، وطريقة الاستعمال، والتكرار
- لا يُعتمد الطلب قبل تأكيدها أو تسجيل سبب الرفض

**معيار القبول**

- [ ] لا يُعتمد الطلب وفيه عنصر غير مؤكد

## PHR-003 · وصفات «وصفتي»

- **الأولوية:** مهم

**القواعد**

- الصيدلية المشاركة في «وصفتي» تُوسم بذلك
- طلب «وصفتي» يُصرف فيه الدواء بقيمة صفر، ويدفع العميل رسوم التوصيل فقط

**معيار القبول**

- [ ] طلب «وصفتي» لا يُحتسب فيه ثمن للدواء

## PHR-004 · موافقة التأمين

- **الأولوية:** لاحقاً

**القواعد**

- يُدخل العميل رقم موافقة التأمين بدل الوصفة إن كانت الصيدلية تقبل التأمين

**معيار القبول**

- [ ] الخيار لا يظهر لصيدلية لا تقبل التأمين

## PHR-005 · استشارة طبيب

- **الأولوية:** لاحقاً

**القواعد**

- رابط لشريك استشارات طبية مرخص عند غياب الوصفة
- المنصة لا تصدر وصفات

**معيار القبول**

- [ ] الرابط يظهر عند طلب دواء وصفي بلا وصفة

## PHR-006 · منع الإعلان عن الأدوية الوصفية

- **الأولوية:** أساسي للإطلاق · **نظامي**

**القواعد**

- الأدوية الوصفية مستبعدة من الإعلانات والعروض والكوبونات والإشعارات والإضافات المقترحة
- إعلان أي دواء غير وصفي يتطلب إدخال رقم موافقة SFDA قبل اعتماده

**معيار القبول**

- [ ] دواء وصفي لا يمكن اختياره في أي إعلان أو عرض أو كوبون
- [ ] إعلان دواء غير وصفي بلا رقم موافقة لا يُعتمد

## PHR-008 · الخصوصية في الإشعارات

- **الأولوية:** مهم

**القواعد**

- الإشعارات ورسائل الجوال لطلبات الصيدلية لا تذكر اسم أي دواء
- تكتفي بعبارة «طلبك من الصيدلية»

**معيار القبول**

- [ ] لا يظهر اسم دواء في أي إشعار لطلب صيدلية

## PHR-009 · تذكير إعادة الصرف

- **الأولوية:** لاحقاً

**القواعد**

- يطلب العميل تذكيراً بموعد إعادة صرف دواء مزمن
- التذكير خدمي لا ترويجي، ويخضع لـPHR-008

**معيار القبول**

- [ ] التذكير لا يذكر اسم الدواء
- [ ] إلغاء الموافقة التسويقية لا يوقف التذكير

## PHR-010 · عدم التجاوب في طلب الدواء

- **الأولوية:** مهم

**القواعد**

- طلب الدواء الذي لم يُسلَّم حالته «يعود للصيدلية»، والمندوب يعيده
- لا تُسترد رسوم التوصيل، ويُسترد ثمن الدواء بعد تأكيد الصيدلية سلامة إعادته، وإلا فلا استرداد

**معيار القبول**

- [ ] طلب الدواء لا يُغلق قبل تأكيد إعادته إلى الصيدلية

## PHR-011 · أسئلة الصيدلي لغير الوصفي

- **الأولوية:** لاحقاً

**القواعد**

- أصناف غير وصفية محددة تتطلب إجابة أسئلة قصيرة
- يراجع الصيدلي الإجابات قبل التجهيز

**معيار القبول**

- [ ] لا يُجهَّز الصنف قبل مراجعة الإجابات

## PHR-012 · طلب الصيدلية

- **الأولوية:** أساسي للإطلاق

**القواعد**

- العميل يكتب طلبه ويرفق الوصفة إن وُجدت، ويدفع التوصيل أولاً ( ORD-013 )
- تنبيه واضح قبل الإرسال: إذا كان الدواء يحتاج وصفة ولم تُرفق، يُلغى الطلب
- الصيدلي يراجع الطلب والوصفة، ويجهز، ويرفق الفاتورة ومبلغها
- يُضاف 5% على العميل، ويدفع، ثم يستلم المندوب

**معيار القبول**

- [ ] طلب دواء وصفي بلا وصفة يُلغى برسالة للعميل
- [ ] المندوب لا يرى الوصفة
