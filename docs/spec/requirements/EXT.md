# الخدمات EXT

## EXT-004 · الصيدليات

- **الأولوية:** أساسي للإطلاق

**القواعد**

- قسم مستقل بطلبات الكتابة ( PHR-012 )
- مراجعة الصيدلي قبل الفاتورة

**معيار القبول**

- [ ] المندوب لا يرى محتوى الوصفة

## EXT-006 · الاستلام الذاتي

- **الأولوية:** أساسي للإطلاق

**القواعد**

- المدير يفعّله لكل متجر، ومنها متاجر المارت
- رسوم التاجر نفسها حسب عقده: رسوم لكل عميل أو نسبة
- المدير يحدد نسبة خصم الاستلام، ومن يتحمله: المنصة أو التاجر أو الاثنان بنسب
- رسوم الخدمة على العميل حسب الإعدادات ( PAY-021 )، ورسم الدفع على التاجر
- التاجر يسلّم العميل بكوده
- حين يضغط التاجر «جاهز» يصل للعميل تذكير: الطلب جاهز، وإذا لم يُستلم قبل نهاية الدوام يُنهى الطلب ويُحصَّل المبلغ
- بعد 60 دقيقة من جاهزية الطلب يصل تنبيه: التطبيق غير مسؤول عن تأخر الاستلام ولا عن تلف الطلب
- بنهاية دوام المتجر يُغلق الطلب «لم يُستلم»، ويُحصَّل المبلغ للتاجر

**معيار القبول**

- [ ] لا يُسلَّم الطلب دون كود العميل
- [ ] التذكير يصل لحظة «جاهز»، والتنبيه بعد 60 دقيقة
- [ ] الطلب غير المستلم يُغلق بنهاية الدوام ويُحصَّل

## EXT-007 · التوصيل لقنوات المتاجر

- **الأولوية:** لاحقاً

**القواعد**

- خدمة توصيل لطلبات المتاجر من قنواتها الخاصة بمناديب المنصة
- تُفعَّل بعد التأكد من متطلبات الترخيص

**معيار القبول**

- [ ] لا تُفعَّل الخدمة قبل تأكيد متطلبات الترخيص

## EXT-008 · حسابات المنشآت

- **الأولوية:** لاحقاً

**القواعد**

- حساب منشأة بفاتورة ضريبية بالرقم الضريبي للمشتري
- حدود إنفاق للموظفين

**معيار القبول**

- [ ] طلب يتجاوز حد إنفاق الموظف لا يكتمل

## EXT-009 · المحلات غير المتعاقدة

- **الأولوية:** أساسي للإطلاق

**القواعد**

- عند إضافة المتجر يحدده المدير «غير متعاقد»، فتعمل طلباته بآلية «اطلب اللي تبي» ( EXT-010 )
- العميل يكتب طلبه ويدفع رسوم خدمة 5 ر.س فقط إلكترونياً
- تنبيه واضح للعميل: المندوب سيشتري ويصدر الفاتورة ويدفع نيابة عنك
- المندوب يشتري ويرفع صورة الفاتورة. النظام يقرأ مبلغها تلقائياً، والمندوب يؤكده
- يُضاف على المبلغ رسوم التوصيل التي يحسبها التطبيق
- يظهر للعميل حساب المندوب البنكي، فيحوّل له الفاتورة والتوصيل
- لا نسبة للمنصة من التوصيل في هذه الخدمة، حقها الـ5 ر.س

**معيار القبول**

- [ ] لا يُرسل الطلب قبل دفع 5 ر.س
- [ ] المبلغ المقروء من الفاتورة يظهر للمندوب ليؤكده أو يصححه
- [ ] المبلغ الظاهر للتحويل = الفاتورة + التوصيل

## EXT-010 · اطلب اللي تبي

- **الأولوية:** أساسي للإطلاق

**القواعد**

- طلب من أي محل موجود على الخريطة، حتى لو غير مضاف في التطبيق
- العميل يحدد المحل على الخريطة، ولا يقبل التطبيق إلا موقعاً داخل محل
- نفس آلية المحلات غير المتعاقدة: رسوم خدمة 5 ر.س، والمندوب يشتري ويرفع الفاتورة، والنظام يقرأ مبلغها، والعميل يحوّل للمندوب الفاتورة والتوصيل
- إذا اشترى المندوب من محل غير المحدد يتحمل المسؤولية
- تظهر للمندوب فقط إذا وافقت الإدارة على تشغيله لهذه الخدمة

**معيار القبول**

- [ ] موقع خارج محل مرفوض
- [ ] المندوب غير الموافق عليه لا يرى هذه الطلبات
