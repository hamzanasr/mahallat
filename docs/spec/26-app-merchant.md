# تطبيق التاجر

### تطبيق التاجر · المطاعم والمحلات

يعمل على جوال أندرويد أو آيفون، وعلى التابلت بنفس الشاشات. العميل والمندوب يظهران برقم تعريف فقط.

#### شاشة: 1 · الطلبات

يصل الطلب بعد قبول المندوب وحالته «جاري التجهيز». عدّاد 3 دقائق لتعديل المدة مرة واحدة، وبعده تُعتمد المدة الافتراضية. «الطلب جاهز للاستلام» وحده يجعل الطلب جاهزاً. لا زر رفض، والعميل برقم تعريف فقط.
