# تقارير التاجر

38 تقريراً تظهر للتاجر في «التقارير» بلوحته، وملخصها في تطبيقه. الصورة في «داش التاجر ← التقارير».

- كل تقرير: فلتر الفترة والفرع، والمقارنة بالفترة السابقة، وتصدير Excel وPDF.
- إرسال تلقائي أسبوعي أو شهري للبريد لمن يختاره التاجر.
- مدير الفرع يرى فرعه فقط، والمالية لمن له صلاحيتها.
- العميل والمندوب يظهران برقم تعريف فقط، بلا أسماء ولا أرقام تواصل ولا عناوين.
- الأرقام نفسها في التقرير والكشف ولوحة الإدارة، بالتعريفات الموحدة.
