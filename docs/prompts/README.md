# طريقة استخدام ملفات الخطوات

كل ملف هنا خطوة واحدة. تعطيها للوكيل في Antigravity هكذا:

```
نفّذ الخطوة docs/prompts/phase-1/1.2-supabase-core.md
ابدأ بخطة تنفيذ واعرضها علي قبل أي تعديل.
```

## دورة كل خطوة

1. **الخطة:** الوكيل يعرض ما سيبنيه. اقرأها. لا توافق على شيء لم تفهمه، اسأله «اشرح لي هذا بالعربي البسيط».
2. **التنفيذ:** يكتب الكود ويشغّل الأوامر. إذا طلب إذنك لتشغيل أمر، اقرأه ووافق.
3. **التجربة:** جرّب بنفسك بالخطوات التي يكتبها لك. لا تنتقل قبل ما تشوف النتيجة بعينك.
4. **الحفظ:** تأكد أنه حدّث `docs/PROGRESS.md` وحفظ في Git ورفع إلى GitHub.
5. **ارجع لـ Claude** بعد كل خطوة أو مرحلة، وأرسل له `docs/PROGRESS.md`، ليراجع ويعطيك الخطوة التالية أو يعدّل الخطة.

## قواعد تحميك من المشاكل

- **خطوة واحدة في المرة.** إذا بدأ الوكيل يبني أشياء من خطوات لاحقة، أوقفه.
- **محادثة جديدة لكل خطوة** في Antigravity. المحادثات الطويلة تجعل الوكيل ينسى القواعد.
- **لا تلصق مفاتيح سرية في المحادثة** إذا كان يكفي أن تضعها بنفسك في ملف `.env`. الوكيل يقول لك اسم المتغير وأنت تلصق القيمة في الملف.
- **إذا ظهر خطأ** استخدم `when-stuck.md`.
- **إذا خربت الأمور** بعد تعديل، اطلب من الوكيل: «ارجع لآخر حفظ في Git» (هذا فائدة الحفظ بعد كل خطوة).
