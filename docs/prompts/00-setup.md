# المرحلة 0: التجهيز

هذه خطوات تنفذها **أنت بيدك** مرة واحدة. خذ وقتك فيها، وإذا وقفت عند أي خطوة ارجع لـ Claude واكتب له رقمها وما ظهر لك.

> **مهم:** كل الحسابات باسمك أنت وبإيميلك، لأنك مالك المشروع. احفظ كل كلمة مرور ومفتاح في مدير كلمات مرور (مثل Bitwarden أو 1Password)، ولا ترسلها في أي محادثة.

## 1. البرامج على جهازك

1. **Node.js**: من nodejs.org حمّل نسخة **LTS** وثبتها بالخيارات الافتراضية.
2. **Git**: من git-scm.com حمّل Git for Windows وثبته بالخيارات الافتراضية.
3. افتح **PowerShell** واكتب هذه الأوامر واحداً واحداً. كل أمر يجب أن يطبع رقم إصدار:

   ```powershell
   node -v
   npm -v
   git -v
   ```

4. عرّف Git باسمك (غيّر الاسم والإيميل):

   ```powershell
   git config --global user.name "اسمك"
   git config --global user.email "your@email.com"
   ```

5. **Antigravity**: عندك مثبت. افتحه وسجل دخولك.
6. **على جوالك**: ثبت تطبيق **Expo Go** من App Store أو Google Play. هو الذي تجرب فيه تطبيق العميل أثناء البناء.

## 2. الحسابات

| الخدمة | الرابط | ماذا تفعل |
|---|---|---|
| GitHub | github.com | أنشئ حساباً. هنا تُحفظ نسخة من الكود |
| Supabase | supabase.com | أنشئ حساباً، ثم مشروعاً جديداً اسمه `delivery-dev`. اختر أقرب منطقة خوادم متاحة لك. **احفظ كلمة مرور قاعدة البيانات** التي يطلبها |
| Expo | expo.dev | أنشئ حساباً. نحتاجه لاحقاً لبناء التطبيقات |

حسابات **ميسر** و**OneSignal** ومزود الرسائل نفتحها في مراحلها، لا الآن.

## 3. مجلد المشروع

1. فك ضغط الملف الذي أرسله لك Claude إلى مسار قصير **بلا مسافات ولا حروف عربية وخارج OneDrive**، مثل:

   ```
   C:\dev\mahallat
   ```

   لماذا خارج OneDrive؟ لأن المشروع سيحتوي عشرات آلاف الملفات الصغيرة، ومزامنة OneDrive تعطّلها وتبطئ الجهاز.

2. في Antigravity: **File ← Open Folder** واختر المجلد.
3. تأكد أنك ترى في الشجرة على اليسار: `AGENTS.md` ومجلد `docs`.

## 4. أول رسالة لوكيل Antigravity

افتح نافذة الوكيل (Agent) واكتب له:

```
اقرأ AGENTS.md ثم docs/ROADMAP.md ثم docs/prompts/README.md.
بعدها نفّذ الخطوة docs/prompts/phase-1/1.1-project-skeleton.md.
ابدأ بخطة تنفيذ واعرضها علي قبل أي تعديل.
```

راجع الخطة التي يعرضها. إذا فهمتها وافق، وإذا فيها شيء غير واضح اسأله عنه قبل الموافقة.
