# الخطوة 1.1: هيكل المشروع واللغتين

## السياق

بداية المشروع. المجلد فيه الآن `AGENTS.md` ومجلد `docs` فقط. اقرأ `AGENTS.md` أولاً، فيه التقنية المعتمدة وقواعد العمل.

## المطلوب

1. **Monorepo بـ npm workspaces** في جذر المجلد:
   - `package.json` في الجذر فيه `workspaces: ["apps/*", "packages/*"]` وسكربتات: `dev:web`، `dev:customer`، `typecheck`، `lint`، `test`.
   - `.gitignore` يشمل `node_modules` وكل ملفات `.env*` ما عدا `.env.example`، ومخرجات البناء.
   - `.editorconfig` وإعداد Prettier موحد.
2. **`apps/web`**: Next.js بأحدث إصدار مستقر، App Router، TypeScript، Tailwind، ESLint.
   - صفحة رئيسية مؤقتة بالعربي فيها اسم المنصة وزر تبديل اللغة.
   - `<html lang dir>` يتغير حسب اللغة: `ar` مع `rtl`، و`en` مع `ltr`.
3. **`apps/customer`**: Expo بأحدث SDK مستقر، TypeScript، expo-router.
   - شاشة رئيسية مؤقتة بالعربي وزر تبديل اللغة.
   - الاتجاه RTL في العربي وLTR في الإنجليزي. مسموح أن يعيد التطبيق تحميل نفسه عند تبديل اللغة إذا كان هذا ما يتطلبه React Native.
   - اللغة الافتراضية العربية حتى لو كانت لغة الجوال إنجليزية.
4. **`packages/shared`**:
   - `i18n/ar.json` و`i18n/en.json`: كل نصوص الواجهة للويب والتطبيقات من هنا. مفاتيح مرتبة حسب الشاشة (`home.title`، `common.switchLanguage`…).
   - دالة مساعدة لاتجاه النص حسب اللغة.
   - مجلد فارغ مجهز للأنواع المولّدة من Supabase لاحقاً.
   - الويب وتطبيق العميل يستوردان منه.
5. **`.env.example`** في كل تطبيق يحتاجه، بأسماء المتغيرات فقط.
6. **`README.md`** في الجذر بالعربي: ما هو المشروع، وكيف يشغله شخص جديد على Windows خطوة بخطوة.
7. **Git و GitHub:**
   - `git init` وأول حفظ.
   - ساعد المالك ينشئ مستودعاً **خاصاً (Private)** على GitHub اسمه `mahallat`، واربطه وارفع.
   - إذا طلب Git تسجيل الدخول سيفتح المتصفح. اشرح للمالك ذلك قبل تشغيل الأمر.

## لا تفعل

- لا تنشئ تطبيقي المندوب والتاجر الآن.
- لا تربط Supabase الآن (الخطوة التالية).
- لا تصمم واجهات. نص وزر فقط.

## تعرف أنها نجحت حين

- [ ] `npm install` من الجذر ينجح بلا أخطاء.
- [ ] `npm run dev:web` ← فتح `http://localhost:3000` يعرض الصفحة بالعربي من اليمين لليسار، وزر اللغة يقلبها للإنجليزي من اليسار لليمين.
- [ ] `npm run dev:customer` ← المالك يمسح رمز QR بتطبيق Expo Go في جواله، فيرى الشاشة بالعربي RTL، وزر اللغة يقلبها للإنجليزي LTR.
- [ ] تغيير نص في `packages/shared/i18n/ar.json` يظهر في الويب والتطبيق معاً.
- [ ] `npm run typecheck` و`npm run lint` بلا أخطاء.
- [ ] الكود موجود على GitHub في مستودع خاص.

> ملاحظة للمالك: جوالك وجهازك يجب أن يكونا على **نفس شبكة الواي فاي** حتى يفتح Expo Go التطبيق. إذا لم يفتح، اطلب من الوكيل تشغيله بخيار `--tunnel`.
