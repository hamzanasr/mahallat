# عند ظهور خطأ أو مشكلة

## أولاً: أعطِ الوكيل في Antigravity هذه الرسالة

انسخها، واملأ ما بين القوسين:

```
ظهرت مشكلة.
ماذا كنت أفعل: [مثال: شغلت npm run dev:customer ومسحت الرمز بالجوال]
ماذا توقعت: [مثال: تفتح الصفحة الرئيسية بالعربي]
ماذا حصل: [مثال: شاشة حمراء فيها خطأ]
نص الخطأ كاملاً:
[الصق الخطأ هنا]

المطلوب:
1. اشرح لي سبب المشكلة بالعربي البسيط قبل أي تعديل.
2. أصلح السبب فقط، ولا تعدّل ملفات لا علاقة لها بالمشكلة.
3. قل لي كيف أتأكد أنها انحلت.
4. سجّل المشكلة وحلها في docs/PROGRESS.md تحت «ملاحظات ومشاكل».
```

## ثانياً: إذا حاول الوكيل مرتين ولم تنحل

ارجع لـ Claude وأرسل له:

- نص الخطأ كاملاً
- ما جربه الوكيل (انسخ آخر ردين منه)
- ملف `docs/PROGRESS.md`

## علامات أن الوكيل يدور في حلقة

أوقفه فوراً إذا:

- عدّل نفس الملف أكثر من 3 مرات لنفس الخطأ
- بدأ يحذف ملفات أو جداول ليتخلص من الخطأ
- اقترح تغيير التقنية المستخدمة (مثل استبدال Supabase أو Expo)
- قال إن الخطأ انحل وأنت ما زلت تراه

وقل له: «توقف. ارجع لآخر حفظ في Git، واشرح لي المشكلة قبل أي محاولة جديدة».
